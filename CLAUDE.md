# CLAUDE.md

Este archivo existe por compatibilidad con editores que leen `CLAUDE.md`. La fuente principal de reglas es `AGENTS.md`.

Antes de actuar, leer:

1. `AGENTS.md`
2. `docs/CONSTITUCION.md`
3. `docs/REGLAS-IA.md`
4. `docs/ROADMAP.md`
5. `docs/PROGRESO.md`
6. La spec activa en `specs/`

Reglas mínimas:

- Una fase y una tarea por vez.
- No avanzar sin la palabra “aprobado”.
- No escribir código sin spec aprobada.
- No hacer commit sin proponer antes el mensaje.
- No hacer push sin aprobación.
- No exponer secretos ni datos personales.
- Usar solo tokens de marca.
- Actualizar `docs/PROGRESO.md` después de cada tarea.
