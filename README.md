# Pedacito de Arte — TFI

Sitio web de catálogo y encargos de papelería artesanal. No es una tienda con pagos: los productos se muestran, se personalizan y el encargo se deriva al WhatsApp del taller.

## Estado

**Fase actual:** F0 — documentación y arnés del agente completados, pendientes de aprobación.  
Todavía no hay código de aplicación ni dependencias instaladas.

## Stack

- React 18 + Vite
- React Router
- Tailwind CSS 3 + DaisyUI 4
- Supabase Postgres + Storage
- Netlify + Netlify Functions
- WhatsApp mediante enlace `wa.me`

## Productos

- Agendas
- Agendas Docentes
- Anotadores
- Revistas para Colorear
